# Groups

The list **Manage → Groups** shows every group you have rights on, with the organisation each
group belongs to. An organisation admin sees the groups of their own organisations, a group
admin or agent only their own groups, the superuser everything.

The list is an entry point: a group's name opens that group's page with its tabs (overview,
settings, staffing, agenda, queue, emergency closure). The organisation's name opens the
organisation's page, if you may open it. A group's page shows the path **Groups ›
organisation › group** at the top, so you always see where you are. Changes are made on the
group's own page only, never in the list.

## Searching and filtering

- **Search by name** finds groups whose name or web address contains the text, ignoring case.
  The page does not show the typed text again: it only says that a search is active, so a
  personal-data value typed in never comes back onto the screen.
- **Organisation** narrows the list to one organisation. The choice offers only organisations
  you see groups of, and appears only when there is more than one.
- **Clear filters** shows the whole list again. The count above the table says what you see
  now; with a filter it also says how many groups there are in all.

A filter value outside your rights is ignored: the list never shows more than your role may
see.

## Columns

- **Duration**: how long an appointment in the group takes.
- **Shortfalls**: how many slots in the coming period have more appointments than agents. The
  notice opens the agenda at the first shortfall. Shown only if you may see the group's
  appointments.
- **Public page**: the group's appointment page as participants see it.

## New group

**New group** (organisation admins and the superuser) creates a group in one of your
organisations. You then set up staffing, texts and channels on the group's page.
